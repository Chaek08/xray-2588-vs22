# Порт xrCore build 2588 на Visual Studio 2022
## Ключевые изменения
* Добавлен адекватный выбор разрешений экрана
* Добавлена возможность настраивать Field of View
* Обновлён DirectInput с 7 на 8
* Портирована компиляция шейдеров из релиза
* Портирована файловая система из релиза
* Портирован менеджер памяти (xrMemory) из релиза
## Гайд по сборке
1. Открываем проект XR_3DA_2588.sln
2. Выбираем конфигурацию Release (другие не работают)
3. Нажимаем на Сборка -> Собрать решение
4. После окончания сборки заходим в папку Release и копируем оттуда папку bin в папку с билдом (ЗАМЕНА ОБЯЗАТЕЛЬНА)
5. Копируем содержимое из папки new_resources в папку с билдом
